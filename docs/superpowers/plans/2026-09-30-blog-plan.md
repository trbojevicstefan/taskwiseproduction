# Taskwise public blog

Approved architecture: Firebase project `taskwiseai-v0`, existing `(default)` Firestore database, isolated `taskwise_blog_posts` collection. n8n writes approved Google Sheet topics and exposes published posts through a read-only public feed. Next.js server rendering reads this feed; no deploy is needed per post. Existing MongoDB application data remains separate. Google Sheet belongs to team@n8nlab.io. Publish Monday/Wednesday/Friday at noon Europe/Belgrade. At least two distinct HTTPS images per topic.
